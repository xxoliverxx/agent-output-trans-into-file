# Agent 回答转文本文件

把 ChatGPT 等智能体的回答转化为 DOCX / PDF / HTML / Markdown 文件，**保留原始结构，只增强形式**，让回答更便于阅读。

## 在线使用

GitHub Pages：https://xxoliverxx.github.io/agent-/

## 本地使用

双击 `agent回答转文本文件.html` 在浏览器中打开即可。

## 为什么需要这个工具

在使用 ChatGPT、Claude、TRAE 等智能体时，你可能会遇到这些问题：

- **对话框里看回答，易读性差**：智能体的回答往往是长段文字堆叠，标题层级不明显，重点不突出，在对话框里滚动阅读很费劲
- **复制粘贴到 Word 后格式混乱**：直接粘贴到 Word 会丢失所有结构，手动排版又太耗时
- **想保存归档但格式不统一**：有时想要 Word 批注，有时想要 PDF 归档，有时想要 HTML 在线看，需要多种格式
- **回答里的逻辑结构被淹没**：智能体回答其实有自己的组织形式（标题、列表、箭头流程图、结论句），但在对话框里这些结构不够醒目

这个工具就是解决这些问题的：**粘贴进去，一键得到重点突出、结构清晰的文档**。

## 核心设计原则

1. **保留原始结构**：不重组原文的逻辑顺序、分段、箭头图，只对"形式"做增强
2. **重点突出（金字塔原理）**：结论句加粗+背景色，重点概念橙色高亮，关键词标记
3. **单文件即用**：双击 `agent回答转文本文件.html` 即可在浏览器使用，无需安装任何环境
4. **多格式导出**：一键导出 DOCX / PDF / HTML / Markdown
5. **四种模板风格**：学术阅读、简洁、普通文档风、易读重排风，适应不同场景

## 四种模板风格

| 模板 | 风格特点 | 适用场景 |
|------|---------|---------|
| 学术阅读模板（推荐） | 深蓝/蓝/橙三级标题，绿色结论块，橙色重点块，黄色关键词高亮，圆角边框 | 通用场景，学术论文阅读 |
| 简洁模板 | 去除装饰，纯净排版 | 偏好极简风格 |
| 普通文档风 | 双色块系统：浅蓝底+深蓝斜体（软强调），浅橙底+橙色加粗+`>>`前缀（硬强调），无边框无圆角，箭头流无背景 | 学术文档、正式报告 |
| 易读重排风 | 普通文档风基础上融合 Kami 设计系统：暖色羊皮纸底(#F5F4ED)，墨蓝单色调(#1B365D)，衬线标题，暖灰正文，克制的字重(400/500) | 长文阅读、沉浸式学习 |

### 普通文档风设计细节

- **软强调块**（结论/提示）：#F2F7FB 浅蓝底 + #1F4E79 深蓝斜体文字，无边框无圆角
- **硬强调块**（重点概念）：#FFF3E0 浅橙底 + #C55A11 橙色加粗文字 + `>>` 前缀，无边框无圆角
- **箭头流**：居中、加粗、深蓝文字，无背景色
- **标题**：统一深蓝色，通过字号大小区分级别
- **无黄色关键词高亮**

### 易读重排风设计细节（融合 Kami）

- 在普通文档风的双色块基础上：
- **页面底色**：#F5F4ED 暖羊皮纸色，非纯白
- **标题字体**：衬线体（思源宋体/STSong），字重 500
- **正文字体**：无衬线体，字重 400，暖灰色 #3D3D3A
- **行间距**：标题 1.3，正文 1.55（阅读优化）
- **代码块**：暖色边框 #E8E6DC，暖色底 #EFEEE6
- **设计理念**：Kami 极简——单一墨蓝强调色，暖色系，衬线标题提升正式感

## 使用方法

1. 双击 `agent回答转文本文件.html` 在浏览器中打开
2. 在左侧文本框**粘贴**智能体的回答，或**上传** .md / .txt 文件
3. 在左下角**选择模板风格**（学术阅读 / 简洁 / 普通文档风 / 易读重排风）
4. 右侧实时预览增强排版后的效果
5. 点击顶部按钮导出为 DOCX / PDF / HTML / Markdown

## 智能识别能力

| 结构类型 | 识别方式 | 视觉效果（学术模板） |
|---------|---------|---------|
| 标题 | `##` / 第X阶段 / Step X / 短行 | H1深蓝 / H2蓝色 / H3橙色 |
| 结论句 | 含"核心问题/目标/总结"等关键词 | 绿色背景 + 加粗 |
| 重点概念 | `>>`开头或含"核心/关键/最重要" | 橙色背景 + 加粗 |
| 箭头流 | 连续短行中含 ↓ → | 浅蓝背景 + 居中 + 箭头高亮 |
| 列表 | `-` `*` `•` `数字.` | 标准列表样式 |
| 代码块 | \`\`\` 包裹 | 等宽字体 + 灰底 |
| 行内关键词 | 核心/关键/最重要/重点/注意/失败 | 黄色背景高亮（仅学术模板） |

> **注意**：普通文档风和易读重排风不使用黄色关键词高亮，箭头流无背景色，色块无边框无圆角。

## 技术架构

**纯前端单文件 HTML**，无后端、无构建步骤、无依赖安装。

| 组件 | 技术 | 用途 |
|------|------|------|
| 核心 | 原生 HTML + CSS + JavaScript | 无框架依赖 |
| DOCX 生成 | docx.js (CDN) | 构建 Word 文档 |
| PDF 生成 | html2pdf.js (CDN) | 预览区转 PDF |
| 文件下载 | file-saver.js (CDN) | 触发浏览器下载 |
| Markdown 解析 | marked.js (CDN) | 上传 MD 文件解析 |

## 使用场景

- **学术研究**：把 ChatGPT 关于论文方法、学习路线的回答转为带排版的 Word 文档，方便批注和归档
- **知识管理**：把智能体的回答转为 HTML 或 Markdown，存入笔记系统
- **团队分享**：把 AI 生成的方案转为 PDF，发给团队成员阅读
- **学习笔记**：把 AI 讲解的技术概念转为结构化文档，重点突出便于复习
- **长文阅读**：使用易读重排风模板，暖色底+衬线标题提升沉浸感
