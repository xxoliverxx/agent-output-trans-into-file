## 项目目标

把 ChatGPT 等智能体的回答转化为 DOCX / PDF / HTML / Markdown，**保留原始结构，只增强形式**（契合金字塔原理：结论先行、重点突出），生成便于阅读的文件。以单文件 HTML 网页形式打开即用。

## 技术方案

方案 A：单文件 HTML + CDN 库（docx.js / html2pdf.js / marked.js / file-saver.js）

## 功能清单

### 输入
- [x] 文本框粘贴
- [x] 上传 .md/.txt/.markdown 文件
- [x] 拖拽上传
- [x] 清空按钮

### 智能识别
- [x] 标题（##/第X阶段/Step X/Module X/短行）
- [x] 结论句（含核心问题/目标等关键词）
- [x] 重点概念（>> 开头或含核心/关键/最重要）
- [x] 箭头流（预扫描区域检测，连续 ↓ → 行+短文本行）
- [x] 列表（-/*/•/数字.）
- [x] 代码块（``` 包裹）
- [x] 行内高亮关键词（核心/关键/最重要/重点/注意/不要/错误/失败）

### 输出
- [x] DOCX（docx.js，含标题层级/加粗结论/callout/箭头流/列表/行内高亮）
- [x] PDF（html2pdf.js，A4 格式）
- [x] HTML（带内联样式的独立文件）
- [x] Markdown（标准 MD 语法）
